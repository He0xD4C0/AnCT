# Changelog

## 0.1.0 - 2026-11-04

- Add the initial PRoot Linux environment backend.
- Add the experimental rooted Droidspaces system-container backend.
- Add instance lifecycle, terminal sessions, configuration editing and logs.
- Add offline backup and restore with checksum validation.
- Add signed built-in catalog support and HTTPS custom catalogs.
- Add a clear separation between managed PRoot data and the native runtime.
